# Checkstyle (Optional)

This folder contains the Checkstyle configuration used to detect coding style violations.

## VS Code

1. Install the **Checkstyle for Java** extension.
1. Open the project folder in VS Code.

Workspace settings are provided in `.vscode/settings.json` to point the extension at:

- `config/checkstyle/checkstyle.xml`
- `config/checkstyle/suppressions.xml`
